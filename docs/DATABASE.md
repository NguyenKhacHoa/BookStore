# Thiết Kế Cơ Sở Dữ Liệu (Supabase / PostgreSQL Schema)

Hệ thống sử dụng **Supabase (PostgreSQL)** với 5 bảng quan hệ cốt lõi, kết nối từ Node.js qua thư viện `pg` (Connection Pool + ACID Transaction).

File SQL khởi tạo bảng & dữ liệu mẫu nằm tại: [`supabase/schema_and_seed.sql`](../supabase/schema_and_seed.sql).

## 1. Chi tiết các bảng

### 1.1. Bảng `users` (Người dùng & Phân quyền)
| Cột | Kiểu dữ liệu | Ràng buộc | Mô tả |
| :--- | :--- | :--- | :--- |
| `id` | BIGINT | GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY | Mã người dùng |
| `email` | TEXT | UNIQUE NOT NULL | Email đăng nhập |
| `password_hash` | TEXT | NOT NULL | Mật khẩu đã mã hóa bằng bcrypt |
| `full_name` | TEXT | NOT NULL | Họ và tên |
| `phone` | TEXT | | Số điện thoại liên hệ |
| `address` | TEXT | | Địa chỉ giao hàng mặc định |
| `role` | TEXT | NOT NULL DEFAULT `'user'` CHECK (`'user'`, `'admin'`) | Phân quyền |
| `is_active` | INTEGER | NOT NULL DEFAULT `1` CHECK (`0`, `1`) | `1`: Hoạt động, `0`: Bị khóa |
| `created_at` | TIMESTAMPTZ | NOT NULL DEFAULT `NOW()` | Ngày tạo tài khoản |

### 1.2. Bảng `categories` (Danh mục sách)
| Cột | Kiểu dữ liệu | Ràng buộc | Mô tả |
| :--- | :--- | :--- | :--- |
| `id` | BIGINT | GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY | Mã danh mục |
| `name` | TEXT | UNIQUE NOT NULL | Tên thể loại |
| `slug` | TEXT | UNIQUE NOT NULL | Đường dẫn thân thiện URL |

### 1.3. Bảng `books` (Thông tin sách & Tồn kho)
| Cột | Kiểu dữ liệu | Ràng buộc | Mô tả |
| :--- | :--- | :--- | :--- |
| `id` | BIGINT | GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY | Mã sách |
| `category_id` | BIGINT | REFERENCES `categories(id)` ON DELETE RESTRICT | Khóa ngoại danh mục |
| `title` | TEXT | NOT NULL | Tên cuốn sách |
| `author` | TEXT | NOT NULL | Tên tác giả |
| `price` | INTEGER | NOT NULL CHECK (`price >= 0`) | Giá bán (VNĐ) |
| `stock` | INTEGER | NOT NULL CHECK (`stock >= 0`) | Số lượng tồn kho |
| `cover_image` | TEXT | DEFAULT `'/images/default-book.png'` | Đường dẫn ảnh bìa |
| `description` | TEXT | | Mô tả tóm tắt nội dung |
| `is_active` | INTEGER | NOT NULL DEFAULT `1` CHECK (`0`, `1`) | `1`: Đang bán, `0`: Ẩn |
| `created_at` | TIMESTAMPTZ | NOT NULL DEFAULT `NOW()` | Ngày thêm sách |

### 1.4. Bảng `orders` (Đơn hàng)
| Cột | Kiểu dữ liệu | Ràng buộc | Mô tả |
| :--- | :--- | :--- | :--- |
| `id` | BIGINT | GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY | Mã đơn hàng |
| `user_id` | BIGINT | REFERENCES `users(id)` ON DELETE RESTRICT | Khách hàng đặt mua |
| `total_amount` | INTEGER | NOT NULL CHECK (`total_amount >= 0`) | Tổng giá trị đơn hàng (VNĐ) |
| `shipping_address` | TEXT | NOT NULL | Địa chỉ nhận hàng |
| `phone` | TEXT | NOT NULL | SĐT người nhận |
| `payment_method` | TEXT | NOT NULL DEFAULT `'COD'` | Phương thức thanh toán (`COD`, `VIETQR`) |
| `payment_status` | TEXT | NOT NULL DEFAULT `'UNPAID'` CHECK (`'UNPAID'`, `'PAID'`, `'REFUNDED'`) | Trạng thái thanh toán / hoàn tiền |
| `transaction_code` | TEXT | UNIQUE | Mã giao dịch VietQR (`DH<orderId><random>`) |
| `return_reason` | TEXT | NULL | Lý do khách hàng yêu cầu hoàn hàng |
| `status` | TEXT | NOT NULL DEFAULT `'PENDING'` | `PENDING`, `CONFIRMED`, `SHIPPING`, `COMPLETED`, `CANCELLED`, `RETURN_REQUESTED`, `RETURNED`, `RETURN_REJECTED` |
| `created_at` | TIMESTAMPTZ | NOT NULL DEFAULT `NOW()` | Thời điểm đặt hàng |

### 1.5. Bảng `order_items` (Chi tiết từng sách trong đơn)
| Cột | Kiểu dữ liệu | Ràng buộc | Mô tả |
| :--- | :--- | :--- | :--- |
| `id` | BIGINT | GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY | Mã chi tiết |
| `order_id` | BIGINT | NOT NULL REFERENCES `orders(id)` ON DELETE CASCADE | Thuộc đơn hàng nào |
| `book_id` | BIGINT | NOT NULL REFERENCES `books(id)` ON DELETE RESTRICT | Cuốn sách được mua |
| `quantity` | INTEGER | NOT NULL CHECK (`quantity > 0`) | Số lượng mua |
| `unit_price` | INTEGER | NOT NULL CHECK (`unit_price >= 0`) | Đơn giá cố định tại thời điểm mua |
